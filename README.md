
# Project Knowledge Base Website

A simple web application for organizing, searching, and sharing
software project documentation.

## Features

- Browse software projects
- Search by project name and technology
- Filter projects by category
- View project descriptions and technologies
- Read prerequisites and installation instructions
- Open GitHub repository links
- Add, edit, and delete projects through the admin page

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Getting Started

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open index.html using Live Server.
5. Navigate to Projects or Admin to explore the features.

## Data Storage

This version uses browser localStorage.
Project data is stored in the current browser and is not
automatically shared between different users or computers.
